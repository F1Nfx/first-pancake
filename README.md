## About the Project

**First Pancake** is my first project created with the Godot game engine. It is a practical learning project focused on exploring the structure of a Godot project, working with scenes and assets, and experimenting with game-development tools.

The repository contains the project files and resources. The gameplay and feature set may change as development continues.

## Project Setup

The project configuration currently specifies:

- **Engine:** Godot 4.7
- **Renderer:** Forward+
- **Physics:** Jolt Physics for 3D physics
- **Main project viewport:** 1500 × 900
- **Autoload:** `UiSound` for shared UI sound functionality

## Project Structure

```text
first-pancake/
├── assets/                 # Game assets
├── scenes/                 # Godot scenes
├── scripts/                # Game scripts
├── themes/                 # UI themes and styling resources
├── icon.svg                # Project icon
└── project.godot           # Godot project configuration
```

## Open the Project

1. Install **Godot 4.7**.
2. Clone this repository:

   ```bash
   git clone https://github.com/F1Nfx/first-pancake.git
   ```

3. Open Godot's Project Manager.
4. Choose **Import** and select the `project.godot` file from the cloned repository.
5. Open the project and run the configured main scene with **F6** (current scene) or the project with **F5** (main scene).

## Project Status

This is an experimental learning project. The repository is mainly intended to document my progress with Godot and game development.
